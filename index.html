Connect your database

This poll needs a free Firebase Realtime Database to sync votes live across phones. Paste your config into the file, then reload.

Show 5-step setup
  1. Go to console.firebase.google.com and create a project (free).
  2. Build → Realtime Database → Create → start in test mode.
  3. Project settings → Your apps → add a Web app → copy the firebaseConfig.
  4. Open this HTML file, find firebaseConfig near the bottom, paste your values (keep databaseURL).
  5. Save, re-host / reopen. Done.
